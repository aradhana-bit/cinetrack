# 🎬 CineTrack

**Discover. Track. Watch. Repeat.**

CineTrack is a modern, responsive movie discovery and tracking web application built to make exploring and organizing movies effortless. Discover trending titles, search for your favorite films, explore movie details, and maintain a personal watchlist — all in one place.

## ✨ Features

- **Movie Discovery:** Explore popular, trending, and recommended movies.
- **Smart Search:** Quickly find movies by their titles.
- **Personal Watchlist:** Add movies to your watchlist and manage what you want to watch.
- **Movie Details:** Explore information about movies, including descriptions and other available details.
- **Responsive Design:** Enjoy a seamless experience across desktops, tablets, and mobile devices.
- **Fast Performance:** Powered by Vite for a fast development experience and optimized builds.
- **Modern UI:** Clean, intuitive, and user-friendly interface.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React.js | Component-based user interface |
| Vite | Development server and build tool |
| JavaScript (ES6+) | Application logic |
| Tailwind CSS | Responsive styling |
| TMDB API | Movie data and information |

## 🚀 Getting Started

Follow these steps to run CineTrack locally.

### 1. Clone the Repository

```bash
git clone https://github.com/aradhana-bit/cinetrack.git
```

### 2. Navigate to the Project Directory

```bash
cd cinetrack
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

If your project uses the TMDB API, create a `.env` file in the project root:

```env
VITE_TMDB_API_KEY=your_api_key
```

Replace `your_api_key` with your actual TMDB API key. Never commit private credentials to GitHub.

### 5. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to explore CineTrack.
