## Overview

CineTrack is a modern movie discovery and tracking web application designed to make exploring and organizing movies simple and convenient.

It provides a centralized space to discover movies, search for titles, explore movie information, and maintain a personal watchlist.

Built with React and Vite, the application focuses on interactive user experiences, reusable components, and efficient state management.

## Key Features

- **Movie Discovery:** Explore available movie collections.
- **Smart Search:** Find movies using title-based search.
- **Personal Watchlist:** Organize movies you want to watch.
- **Movie Information:** Explore details about selected movies.
- **Interactive Interface:** Navigate through a responsive user interface.
- **State Management:** Manage application data using Redux Toolkit.
- **Data Visualization:** Use Recharts for chart-based visualizations where implemented.

## Getting Started

Follow these steps to run CineTrack locally.

**1. Clone the repository**

```bash
git clone https://github.com/aradhana-bit/cinetrack.git
```

**2. Navigate to the project directory**

```bash
cd cinetrack
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.
